# Зачарованная библиотека

Личное адаптивное веб-приложение: виртуальные книжные полки, читательский дневник и мягкая статистика без целей и геймификации.

Проект ведётся по SDD (Spec-Driven Development). Источником истины служат документы спецификации:

- [Продуктовая спецификация](specs/001-enchanted-library/spec.md)
- [Сценарии и критерии приёмки](specs/001-enchanted-library/acceptance.md)
- [Технический дизайн](specs/001-enchanted-library/design.md)
- [План реализации](specs/001-enchanted-library/plan.md)

Статус: discovery завершён, спецификация v0.1 подготовлена к согласованию.

## Поиск в ЛитРес

Поиск объединяет Google Books, Open Library и ЛитРес. Для ЛитРес задайте серверные переменные `LITRES_APP_ID` и `LITRES_SECRET_KEY`, полученные у партнёрского отдела ЛитРес (`partners@litres.ru`). Без них остальные каталоги продолжают работать, а адаптер ЛитРес безопасно пропускается.
